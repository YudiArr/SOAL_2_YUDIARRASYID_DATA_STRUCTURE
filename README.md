Soal 2: Menerapkan Enkapsulasi dan Method (Bobot: 40%)
1.	Ubah atribut ipk menjadi private.
2.	Buat getter dan setter untuk mengakses serta memperbarui nilai ipk.
3.	Tambahkan method cekKelulusan() untuk menampilkan status kelulusan:
•	IPK ≥ 3.00 → Lulus
•	IPK < 3.00 → Belum Lulus
4.	Tambahkan method updateIpk(double ipkBaru) untuk memperbarui IPK salah satu mahasiswa berdasarkan input pengguna.
5.	Setelah IPK diperbarui, tampilkan kembali informasi mahasiswa dan status kelulusannya.
